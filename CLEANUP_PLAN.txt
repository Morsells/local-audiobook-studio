LOCAL AUDIOBOOK STUDIO — SAFE CLEANUP PLAN
==========================================

This cleaner is intended to be copied into the EXISTING project.
It does not create a replacement project.

ALWAYS KEPT
-----------
- .audiobook_data
  Your book projects, translated text, queues/caches, generated output,
  reference voice and metadata are protected.
- .venv
- .venv-chatterbox
- .streamlit
- src
- app.py
- models/chatterbox
- models/kokoro-v1.0.onnx
- models/voices-v1.0.bin
- Chatterbox Fast Quality production files
- translation/Ollama pipeline
- M4B/export pipeline
- standard Start/Stop/Status launchers

REMOVED
-------
- all benchmark_chatterbox* output folders
- all Benchmark-Chatterbox-*.bat launchers
- all Profile-Chatterbox-*.bat launchers
- benchmark/profiler Python scripts
- abandoned FP16 / persistent graph / EOS batching / S3 compile experiments
- Triton benchmark setup files and triton-windows package from .venv-chatterbox
- old CHANGELOG_V3*, UPGRADE_TO_V3*, VALIDATION*, CLEANUP_AUDIT* files
- smoke-test WAV files
- .runtime and logs (recreated empty)
- Python __pycache__ directories under src/scripts/tests
- rejected Kikiri stack:
    .venv-kikiri
    models/kikiri
    Kikiri setup/server/download/test files
- rejected Piper model/download files
- tests that only cover abandoned benchmark experiments

QWEN
----
The BAT asks whether Qwen should also be removed.

If YES:
- .venv-qwen
- models/qwen3-tts
- Start-Audiobook-Studio-With-Qwen.bat
- Qwen server/downloader scripts

If NO:
Qwen remains untouched.

IMPORTANT
---------
This is a filesystem cleanup. It intentionally does NOT perform a risky bulk
rewrite of app.py / audio.py / start_all.ps1 in the same destructive step.
After the cleaner has run and the Chatterbox production path has been verified,
dead Piper/Kikiri/Qwen code branches can be removed in a separate tested
source-code refactor without risking your working audiobook data.
