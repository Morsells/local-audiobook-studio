LOCAL AUDIOBOOK STUDIO
======================

PRIMARY WORKFLOW
----------------
1. Start the app with Chatterbox:

   Start-Audiobook-Studio-With-Chatterbox.bat

2. Open:

   http://127.0.0.1:8501

3. Upload/open your PDF, EPUB, TXT or Markdown book.

4. For German or multilingual narration use:

   Chatterbox V3 -> Auto / Fast Quality

   Auto uses the validated FP32 CUDA Graph path when CUDA is available and
   otherwise falls back to Official inference.

5. For lightweight English narration use Kokoro.

6. Qwen3-TTS is retained only as an optional fallback:

   Start-Audiobook-Studio-With-Qwen.bat

TRANSLATION-ONLY MODE
---------------------
For long Ollama/TranslateGemma translation runs without loading a TTS sidecar:

   Start-Audiobook-Studio-Translate.bat

SETUP COMMANDS
--------------
Chatterbox:

   Setup-Chatterbox-GPU.bat

GPU acceleration checks:

   Setup-GPU-Acceleration.bat

Local translation models / Ollama helper:

   Setup-Literary-Translation.bat

STATUS / STOP
-------------
   Status-Audiobook-Studio.bat
   Stop-Audiobook-Studio.bat

LOCAL DATA
----------
Do not delete .audiobook_data. It contains book projects, translations, queues,
caches, generated output, metadata and project-local voice references.

The normal model runtime is local-only. Chatterbox loads from local files and
sidecars bind to 127.0.0.1.
